before.map and after.map are hand-written synthetic examples of GNU ld map syntax,
not vendor data and not files generated by a toolchain on the author's machine.
They model separate FLASH and RAM regions, .data with a distinct LMA, .bss whose
displayed LMA does not represent file-backed load bytes, discarded inputs and
debug sections. Indented input sections must not be counted a second time.

Expected before: FLASH 0x130 (304), RAM 0x90 (144).
Expected after: FLASH 0x180 (384), RAM 0xb0 (176).
Growth: FLASH +80, RAM +32.

The repository also includes examples/main.c and examples/layout.ld with commands
for generating a map using GNU gcc/ld and checking it against readelf/size.
Tests include an optional real GNU toolchain integration check when gcc and ld
are present. A skipped integration check is explicitly reported as skipped.
